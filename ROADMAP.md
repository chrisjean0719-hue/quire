# Roadmap

Quire plans folio, quarto, and octavo sheets, fits them on a parent sheet, shifts inner folios for creep, and draws each sheet side. One of the six updates remains.

## Still in the six updates

### Plan comparison (4 hours)

Compare two book specs by sheet count, blank padding, and trimmed waste.

## After the sixth update

These stay after the six updates. They are about 38 hours.

### Padding report (3 hours)

Print where each blank slot sits in the bound book, and offer a page count that removes the padding.

### Diagram marks (3 hours)

Add fold, head, and crop marks to the SVG sheet diagram.

### Reading proof (2 hours)

Walk the imposed sheets in reading order and fail the plan if a page is missing, repeated, or out of sequence.

### Spine width (4 hours)

Take a paper caliper in millimetres and report the spine width of the finished book.

### Cover wrap (4 hours)

Add a cover sheet with turn-ins and a hinge, sized from the trimmed page and the spine width.

### Sewing stations (4 hours)

Place a chosen number of sewing stations along the spine fold and report their distances from the head.

### Endpapers (3 hours)

Add a front and back endpaper pair, and show which sheet they print on.

### Right-to-left books (4 hours)

Mirror the imposition so page 1 stays at the front of a right-to-left book.

### Cut list (4 hours)

List each cut that turns the parent sheet into printed sheets, in order, with the offcut size.

### Press JSON (4 hours)

Write the imposed pages to a JSON file another tool can print without reading the text plan.

### Gutter safety (3 hours)

Warn when a page number would fall inside a chosen inner margin after folding.

Plan comparison is the next update. The current commands plan one book at a time.
